点格棋，海盗版。双方轮流在两个相邻的点之间画一条线，谁补上格子的第四条边，格子就归谁，而且
还能再走一步。图画满，分高者赢。规则就这么多——然后你会花一个小时试图赢过电脑。

96 个关卡，没有一关是规规矩矩的方格。航线绕着宝箱、海船和风暴走，所以有一半的谜题，其实是
棋盘本身的形状。页面顶上那三张就是第 80、88、92 关：蓝线是我画的，金线是电脑画的，金币表示
那个格子已经被拿走了。

## 我第一个独立做的游戏，现在想想有点离谱

[Track Lapse](/apps/track-lapse/) 是在第一份工作里做的，身边还有一整个团队。而同样是 2012 年，
稍晚一点的 Pirate Lines，是第一个代码从头到尾只有我一个人写的。

而且当年的我显然没打算省事：一个真的会下棋的 CPU 对手，会看棋盘、绝不把长链白送给你、能吃
的格子一个不落；蓝牙近距离对战，两台手机在没有网的地方也能找到彼此；基于 Game Center 的
联机对战，带匹配和邀请；排行榜；内购；96 个关卡。

多了十来年经验的今天，这些东西我大概会先掂量掂量再动手。二十几岁的我直接就做了——大概是
因为当时没人告诉他这工作量有多大。

## 美术不是我做的

你看到的每一个像素——海盗、帆船、宝箱、乌云，还有那个 logo——都出自 **天予哥**之手，还有
不少关卡也是他设计的。这游戏之所以好看，全是因为他。

谢谢天予哥。十四年过去了，这套美术一点都不显旧。

## 去玩两把

有个网页版，不用装、不用上架，点开就能玩：

**[songer522.github.io/Grid](https://songer522.github.io/Grid/)**

它和 iOS 版不共用任何代码，但复用了原版的美术和全部 96 张地图，所以你玩到的就是手机上那张
棋盘。CPU 对手也一起搬了过来，还是一样难缠。联机和 Game Center 没跟着来。

## 重新跑起来

这个项目十几年没动过，按 iOS 的时间尺度差不多等于上古。它编译不过，当年最爱用的那些 API
被苹果悄悄删掉了一半；那套布局还坚信全世界的手机都是 320×480，而这件事从 2014 年起就不成立了。

现在它在 iPhone 和 iPad 上都能跑。源码在 [GitHub](https://github.com/songer522/Grid) 上，
2012 年份，橡木桶陈酿。
